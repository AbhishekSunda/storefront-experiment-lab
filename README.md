# Storefront Experiment Lab

A lightweight vanilla JavaScript project for practising production-style DOM experiments on a mock storefront.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- Express (introduced later for API exercises)

## Learning roadmap

1. Build the website-owned storefront
2. Inject and clean up experiment UI
3. Add delegated interactions and event tracking
4. Handle DOM rerenders with `MutationObserver`
5. Support SPA navigation and experiment lifecycle
6. Add scoped responsive experiment styles
7. Implement polyfills, debounce, and throttle
8. Add an Express API and resilient `fetch()` handling
9. Integrate, test edge cases, and prepare an interview walkthrough

## Running locally

Open `index.html` using a local development server such as VS Code Live Server.
